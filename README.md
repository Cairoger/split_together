# SplitTogether

SplitTogether 是繁體中文的離線分帳 App。適合由一人替旅伴、室友或聚餐朋友記帳。首次啟動時帳本為空，所有已儲存的群組、消費與還款都保存在裝置的 SQLite 資料庫。

## 快速聚餐

1. 從首頁點「開始聚餐分帳」，輸入帳單總額。第一次使用也可先點「用範例試一次」，看看兩人平分 NT$600 的結果。範例中的轉帳按鈕只供辨識，隨時可回首頁或開始一筆空白的真實聚餐。
2. 在「今天有哪些人」勾選至少兩人，自己也可勾選。最近出席的朋友會排在前面，每一餐都由你重新選擇。選「新增臨時參與者」可一次輸入「小林、小安、小晴」，名字只留在本餐。想在以後的聚餐重複選取，可用「新增朋友」。
3. 在「誰先付」選一位出席者，按「儲存並看分帳結果」。付款人也分攤自己的一份，取消勾選這位付款人時須重新選擇。按鈕顯示「儲存中…」時請稍候，成功後會直接開啟結果頁並顯示「已儲存」。若儲存失敗，原本的輸入會保留，可直接重試。
4. 結果頁先列出你要轉給誰、轉多少，或你應收多少。需要轉帳時可選擇或開啟自己的轉帳 App。朋友有儲存收款帳號時，可另外複製。實際付款須在銀行 App 中確認。你先付且有應收款時，點「分享分帳清單」即可選擇 LINE 等 App。回到首頁可從「最近聚餐」或「全部聚餐紀錄」重看已儲存的結果。
5. 「複製清單」和「分享分帳清單」使用相同文字。開頭列出用餐當天的日期、總額、付款人與平分人數，接著逐筆列出誰要轉給誰及金額。分攤完全相同時才會列出每人金額。從紀錄再次分享也會保留原日期，清單不含銀行代碼或帳號。

例如四人吃 NT$1,200，由小林先付，四人各分攤 NT$300，其餘三人各轉小林 NT$300。三人平分 NT$1,000 時則為 NT$333.34、NT$333.33、NT$333.33；同一批出席者的尾差依 ID 決定。

## 使用群組帳本

1. 在「首頁」點「建立群組」，填入群組名稱與類型。App 會自動加入「我」。其他成員每行填一位，也可以之後到「成員管理」新增。
2. 點「新增消費」，先填消費金額與項目名稱，再選「誰先付」和「誰要分攤」。如果付款人只是代墊，可在「誰要分攤」取消勾選付款人。展開「更多資料」可調整日期、分類與備註。
3. 新消費預設「平分」。要不均分，可改選下方任一種自訂分帳方式，核對每位成員姓名旁的金額，再點「儲存消費」。金額支援新台幣至小數第 2 位，單筆上限為 NT$99,999,999.99。
4. 開啟「智慧結算」查看建議。實際付款後，點選建議或「記錄還款」，核對雙方與實付金額。部分還款會保留剩餘欠款，全部結清後即可封存群組。
5. 從「消費明細」可編輯或確認刪除消費。還款如需更正，請在「還款紀錄」撤銷錯誤紀錄，再登記正確金額。修改消費時，既有還款會保留。

首頁將「我」在每一組的正餘額加總為應收，負餘額的絕對值加總為應付。每組各自提出還款建議。可從結算頁複製文字清單。在「統計」展開任一群組，或進入群組明細，即可查看分類消費合計。

「設定」中的預設名稱套用於之後建立的群組。既有群組可在「成員管理」重新命名。封存群組可從「群組 → 已封存」查閱或解除封存。清除 App 資料、解除安裝或遺失裝置可能導致帳目遺失，目前沒有雲端同步或匯出功能。

在「設定 → 外觀」可選擇「光亮模式」或「黑暗模式」。外觀會立即套用至整個 App，下次開啟時會沿用這台裝置儲存的選擇。第一次使用或從舊版更新時，預設為光亮模式。

### 自訂消費的分帳方式

| 方式 | 操作 |
|---|---|
| 指定金額 | 直接填每人的金額，合計須等於消費總額。 |
| 按份數分 | 每人從 1 份開始，按「－」「＋」逐份調整，或點份數直接輸入 1～10,000。色條顯示每人的占比。例如 NT$1,200 分成 2：1：1，三人各付 NT$600、NT$300、NT$300。 |
| 百分比 | 第一次選這個方式時，系統會把 100% 平分給當下勾選的人。展開姓名旁的滑桿可逐次調整 1%，點百分比可精確輸入到 0.01%。 |

兩人分帳時，將一人調到 60%，另一人會自動變成 40%。三人以上只會調整正在編輯的人。若想保留某人的比例，展開該人的滑桿，點「其餘人平分」。例如保留 40.01%，另外兩人會分到 30.00% 和 29.99%。

合計不足 100% 時，甜甜圈圖用灰色標出「尚未分配」的部分。超過 100% 時，畫面會顯示超出的比例。調整到剛好 100% 後，才能核對每人金額並儲存。

同一張表單中，切換分帳方式會保留各自輸入的草稿。重新編輯既有消費時，會帶回原付款人、參與者及分攤數值，包含這筆消費使用過的停用成員。

## 常用朋友與銀行 App

- 在「成員管理 → 新增成員」可選擇現有朋友，或填寫姓名並勾選「存為常用朋友」。建立群組也可貼上多行姓名，在儲存前逐一移除。既有成員可從成員選單連結朋友；同名朋友需手動選取。
- 每位朋友可儲存一組收款銀行代碼與帳號。在「設定 → 常用朋友」查看、修改、複製或刪除帳號。清單只顯示末四碼，前導零會保留。群組的文字還款清單只含姓名及還款金額。
- 在「設定 → 我的轉帳 App」選擇自己的付款工具，可與收款人的銀行不同。Android 可搜尋手機上已安裝、可開啟的 App，清單顯示圖示、名稱與目前選擇。已安裝的內建銀行會優先列在「常用銀行」。
- iPhone 可在 Apple「捷徑」建立只有「打開 App」動作的捷徑，再於「我的轉帳 App → 使用我的捷徑」輸入相同名稱。行動郵局提供 App Store 入口，也可透過上述捷徑開啟。中國信託與台新的 iOS 入口依銀行公布的啟動連結設定。[Apple 捷徑說明](https://support.apple.com/zh-tw/guide/shortcuts/apd624386f42/ios) · [中國信託](https://www.ctbcbank.com/content/dam/minisite/long/mobile/PRO_URL.html) · [台新銀行](https://www.taishinbank.com.tw/TSB/personal/digital/Digital-Platform/mobile-banking/online-download/) · [中華郵政](https://www.post.gov.tw/post/internet/B_saving/index.jsp?ID=1651202500081&ID=1651210046972)
- 在「智慧結算」點選自己應付的建議，分別點「複製收款帳號」和開啟所選 App 的按鈕。在銀行端自行確認收款人、輸入金額並完成轉帳，再回到 SplitTogether 登記實付金額。單純複製或離開 App 不會改動餘額。

## 在 Windows 執行 Android 版

此專案沿用既有 Flutter App 與 Android、iOS 平台設定。開發環境使用 Flutter 3.50.0 stable、Dart 3.14.0。請在專案根目錄執行以下指令。

```powershell
flutter pub get
flutter devices
flutter run -d <Android裝置ID>
```

從 `flutter devices` 選擇實際 Android 裝置或模擬器。首次取得依賴與建置工具可能需要連線，安裝後的記帳流程可離線操作。

```powershell
flutter analyze
flutter test
flutter build apk --debug
```

建置後的 APK 位於 `build/app/outputs/flutter-apk/app-debug.apk`。iOS 原生建置與裝置驗證需使用 macOS 與 Xcode。Windows 在此專案中用於開發及測試。

## 從 GitHub 下載 Android 測試版

推送至 `main`、向 `main` 提出或更新 Pull Request 時，GitHub Actions 會檢查程式碼、執行測試並打包 APK。也可以在「Actions → Android preview」手動觸發。建置成功後，在該次執行頁面下方的「Artifacts」下載 ZIP，解壓縮後即可在 Android 測試裝置上安裝 APK。

測試版在桌面顯示為 **SplitTogether Preview**，有獨立的 App ID（`com.example.split_together.preview`）和帳本，可與原本的 SplitTogether 並存。它不會讀取或更新原本的帳本，請不要解除安裝原本的 App。各次建置的測試簽章可能不同；如果 Android 拒絕更新，請換一台測試裝置或模擬器，或僅移除 **Preview** 後重裝。移除 Preview 會刪除其中的測試資料，請勿將唯一一份帳本保存於此。

## 程式與資料

| 位置 | 用途 |
|---|---|
| `lib/domain.dart` | 資料模型、整數金額解析、四種分攤、餘額及貪婪結算演算法 |
| `lib/data/` | Repository、共用寫入驗證、記憶體與 SQLite 實作、schema 與 migration |
| `lib/state.dart` | 透過 ChangeNotifier 載入帳本、在交易提交後刷新畫面 |
| `lib/app.dart`、`lib/ui.dart`、`lib/screens/` | 繁中 Material 3 介面、帳本操作與設定 |
| `test/unit/`、`test/data/`、`test/widget_test.dart` | 計算、持久化及表單操作測試 |

金額使用整數分，百分比使用基點。百分比與權重分攤採最大餘數法，尾差以成員 ID 穩定排序。結算每次配對剩餘欠款與應收金額最大者，可能有其他轉帳次數更少的解。還款只改變餘額，群組總消費僅計入消費紀錄。

正式入口使用 `sqflite`，測試使用 `sqflite_common_ffi` 開啟實際 SQLite 檔案。資料庫版本為 3。第 2 版加入朋友資料，第 3 版加入獨立的快速聚餐紀錄。升級會保留原有群組、消費、還款與朋友資料。消費與分攤以同一筆交易寫入。日期以 UTC 儲存，畫面顯示裝置當地日期。

SQLite 保存銀行代碼、末四碼與帳號密文。`cryptography` 使用 AES-GCM 加密完整帳號，金鑰交由 `flutter_secure_storage` 使用裝置的安全儲存保管。開啟付款 App 時只使用 App 識別碼或捷徑名稱。只有明確點選複製時，完整帳號才寫入系統剪貼簿。

若 Windows 僅建置手機版，而 `flutter pub get` 提示桌面外掛需要符號連結，可在目前 PowerShell 視窗將 `$env:FLUTTER_WINDOWS='false'` 與 `$env:FLUTTER_LINUX='false'` 設定後再執行。

版本驗證結果與平台限制請見 [開發進度](docs/PROGRESS.md)。
