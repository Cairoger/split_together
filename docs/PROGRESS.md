# SplitTogether 開發進度

## 2026-11-20 · 常用朋友、收款帳號與自選轉帳 App

建立群組可批次貼上姓名、檢查重名及移除個別成員。新增成員可從常用朋友挑選，或建立朋友並選填收款帳號。既有成員也能手動連結朋友，保留原本的消費與還款紀錄。

- 收款帳號在裝置加密儲存，預設顯示銀行及末四碼。複製群組還款清單只會帶出姓名與金額。開啟自己的轉帳 App 及登記實付金額各有獨立按鈕。
- 內建中國信託、台新及行動郵局。Android 可從手機已安裝的 App 自選；iPhone 可指定自己建立的「打開 App」捷徑。行動郵局的 iPhone 預設入口為 App Store。
- `flutter analyze` 無問題，`flutter test` 全部 44 項通過。測試涵蓋從舊帳本升級、保留帳號前導零、不同群組使用同一位朋友、密文驗證及開啟 App 後的帳目狀態。
- `flutter build apk --release --split-per-abi` 成功產出三個 APK。已核對手機版為 arm64-v8a，最低 Android 7.0（API 24），APK 簽章通過驗證且憑證指紋與既有版本一致。iOS 介面已通過自動測試，原生啟動與捷徑仍待 iPhone 實機驗證。
- Android API 37 模擬器以測試帳號驗證新增朋友、複製及未安裝行動郵局時的商店提示。原地更新後，所選 App 與帳號前導零均保留。從結算頁開啟所選的時鐘 App 後返回，NT$50 欠款及空白還款紀錄均維持原狀。

## 2026-11-20 · 光亮模式與黑暗模式

「設定 → 外觀」可切換整個 App 的顯示模式。光亮模式使用米白背景、墨綠色應收與磚紅色應付；黑暗模式使用深墨綠背景、薄荷綠色應收與珊瑚色應付。偏好存入既有 SQLite 設定表，舊帳本預設為光亮模式。

- `flutter analyze` 通過。完整 `flutter test` 共 32 項通過，涵蓋重新啟動、連點、儲存失敗後重試，以及切換後保留帳目與餘額。
- `flutter build apk --release --split-per-abi` 通過。ARM64 手機版輸出為 `build/app/outputs/flutter-apk/app-arm64-v8a-release.apk`，已驗證架構與既有簽章。
- Android 17 模擬器以 x86_64 release 版實測。切換後仍停留在設定頁，背景取樣由 `#F6F8F7` 變為 `#101A17`；強制停止並重開後，首頁與設定仍為黑暗模式，再切回光亮模式時顏色正確還原。

## 2026-11-20 · MVP 1.0

沿用既有 Flutter 計數器 App 的套件名稱、Android 和 iOS 專案。開始時 App 目錄沒有 Git 儲存庫，基準 `flutter analyze --no-pub` 及原有的計數器測試均通過。開發環境為 Windows、Flutter 3.50.0 stable、Dart 3.14.0。介面沿用既有 `material_ui`，依鎖定檔解析相容的 SQLite 套件。

| 階段 | 實作與驗證範圍 |
|---|---|
| 1 · 介面基礎 | 繁體中文 Material 3、首頁餘額、底部導覽、初始空帳本與新增入口。 |
| 2 · 群組與成員 | 群組建立與編輯、同交易加入「我」、名稱去空白與去重、成員重新命名與停用、已結清群組可封存與解除封存。 |
| 3 · 消費 | 金額精確至分。四種分帳共用預覽與儲存演算法，支援代付、日期、歷史編輯及刪除確認。 |
| 4 · 結算 | 各組獨立計算餘額、依剩餘應付與應收排序產生建議。支援手動選雙方、部分或全額還款、撤銷還款與即時重算。 |
| 5 · SQLite | 正式啟動使用 schema 1，外鍵限定群組範圍。多表操作放在交易內。記憶體版供測試。沒有自動植入示範資料。 |
| 6 · 驗收 | 計算單元測試、真實 SQLite 檔案、表單操作、寫入失敗與重試、窄螢幕及放大字級。 |
| 7 · 選做 | 可複製純文字建議還款清單。「統計」與群組明細顯示群組消費及分類金額，還款不計入消費。 |

## 操作驗收範例

1. 建立四人群組。A 支付 NT$1,200、B 支付 NT$600，兩筆均由四人平分。群組總消費應為 NT$1,800，A、B 各應收 NT$750、NT$150，C、D 各應付 NT$450。
2. 手動記錄 C 還 A NT$200。A 應收降到 NT$550，C 應付降到 NT$250，群組總消費與分類合計維持原值。同額建議的順序由實際成員 ID 決定。
3. 關閉再開啟 App，核對消費、分攤與還款紀錄。按剩餘建議還清後應顯示「所有帳目已結清」。封存後可從「群組 → 已封存」查閱與解除封存。
